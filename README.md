# Ghareeb Elshaikh - Personal Website

A modern, responsive personal website for tech educator and content creator Ghareeb Elshaikh. Built with clean HTML, CSS, and vanilla JavaScript.

## 🌟 Features

- **Homepage** - Introduction, hero section with statistics, course highlights, testimonials
- **Courses Page** - Complete listing of all available programming courses
- **Consulting Page** - Professional consultation booking form
- **Advertise Page** - Brand partnership and advertising opportunities
- **Responsive Design** - Fully responsive across all devices
- **Modern Animations** - Smooth scroll reveals and hover effects
- **Bilingual Support** - Arabic (RTL) and English content

## 🚀 Getting Started

### Prerequisites

- A modern web browser
- A local web server (optional, for development)

### Installation

1. Clone the repository:
```bash
git clone https://github.com/ghareebghareeb/mysite.git
cd mysite
```

2. Open `index.html` in your browser, or use a local server:
```bash
# Using Python
python -m http.server 8000

# Using Node.js (http-server)
npx http-server

# Using PHP
php -S localhost:8000
```

3. Navigate to `http://localhost:8000` in your browser

## 🔧 Customization

### Changing Colors
Edit the color variables in `styles.css`:
- Primary gradient: `#38bdf8` to `#6366f1`
- Background: Light blue gradients
- Text: `#0f172a` for headings, `#4b5563` for body

### Adding New Courses
1. Add course thumbnail to `assets/` folder
2. Add course card in `courses.html` following the existing structure
3. Update `index.html` if you want to feature it on homepage

### Updating Contact Email
Replace `contact@ghareeb.website` in:
- `consulting.html` (form action)
- `advertise.html` (form action)
